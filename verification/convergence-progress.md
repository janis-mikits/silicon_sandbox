# Convergence guard progress

An independent synthetic acyclic fixture chains 1,500 one-bit AND gates between a changing source and the observed output. It checks that a known 1 reaches the far end, then a source change to 0 settles all 1,500 gates without being mistaken for a 1,024-pass feedback fault.

When the configured pass limit is exhausted, the simulator now stops its pending work, marks the changed and downstream signal cone X, and exposes a diagnostic. The world scheduler pauses, blocks resume, and the UI displays the explanation. A corrected graph clears the convergence diagnostic but remains paused until the player resumes. A new test uses a legal two-stage edge cascade with a deliberately low limit of one pass: independent expected behavior is that the default limit settles both stages at 1, whereas the forced limit leaves their affected outputs X and an unrelated source at 1. Reset after correction restores the authored initial state.

This covers the long-path and guard-response parts of internal scheduler check C08. The low-limit cascade tests fault handling, not oscillator detection. The native Unity Test Runner has not executed this revision. Offline Play Mode source compilation passed with zero warnings or errors. Exact commands are recorded in [benchmark instrumentation](benchmark-instrumentation-progress.md).

A separate self-fed AND loop now checks two independent expected states: a known-zero seed makes `0 AND 1` settle at 0, while an unseeded loop settles at X without a false oscillator report. The paused source-action path also synchronizes any new convergence diagnostic to the scheduler. After these additions, the offline Edit Mode runner passed **161 tests, zero failed**. A true synthetic zero-delay oscillator at the default guard remains unverified.
