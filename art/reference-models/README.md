# Block, pin, and wire visual references

Put example block, pin, connector, and module models here. These are design references, not game-ready assets; the Unity project should import only approved, optimized assets later.

Preferred handoff: an `.fbx` export for each model, with any separate texture images as `.png`. Include a few `.png` screenshots or renders showing the intended front, top, and side appearance, especially when a material or fine detail does not survive FBX export. You may also include the original `.blend` file so its source geometry and materials remain available. Use descriptive names such as `and-gate-example.fbx` and `and-gate-top.png`.

No particular pixel density is fixed by these examples. The canonical [graphics guidance](../../docs/graphics-and-future-tools.md#confirmed-visual-priorities) starts at a configurable 16×16×16 art grid; final geometry and texture density should be chosen after reviewing the references for readability and performance.
