# SiliconSandbox knowledge base index

Read this file first. The numbered file titles retain the revised DOCX's source section numbers. Load the operative subsystem file for a task, then the listed dependencies. Consult [open decisions](docs/open-decisions-and-cautions.md) when a task touches an unresolved rule and the [current research backlog](docs/research-backlog.md) for remaining research. The [original backlog archive](docs/original-research-backlog.md) and [revision history](docs/revision-history.md) preserve source context; they are not a second operative specification or a list of current tasks.

## Source section map

The revised DOCX's sections map directly to the first thirteen subsystem files: Project vision and world, then numbered Sections 1–12 in the order shown in the file guide. Appendices A–D map to graphics and future tools, open decisions and cautions, the archived original research backlog, and revision history. The separate [current research backlog](docs/research-backlog.md) tracks only unanswered follow-ups. A prose reference to “Section 3,” for example, means [physical connections](docs/physical-connections.md); “Section 9” means [saving and recovery](docs/saving-and-recovery.md). Plural section ranges in the migrated prose retain the source wording; use this file guide to resolve each member of a range.
